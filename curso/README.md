Cada path contiene sus módulos. Cada módulo tiene una carpeta `unidades/` con todas las unidades del temario oficial. Cada unidad parte vacía y se va completando a medida que se practica.

La fuente de verdad para los nombres, duraciones y URLs es `curso/_meta/course-hierarchy.json` (espejo del repo privado).
